# akkoord
Project voor het OU-vak Key Topics

De map samples bevat 9102 samples van akkoorden. De akkoorden zijn gegenereerd met behulp van het notatieprogramma Dorico van Steinberg [https://www.steinberg.net/dorico/]().  Er zijn verschillende software instrumenten gebruikt. De instrumenten zijn afkomstig uit de meegeleverde HALion Sonic SE3-bibliotheek. 

Het bestandsformaat is WAV, sample rate 48000 Hz, Signed 16-bit PCM, mono. Omdat de oorspronkelijke opnames nogal wat ruimte innamen, zijn ze ingekort tot 2 seconden per sample.
 
Naamgeving van de akkoordsamples:
